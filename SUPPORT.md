# Getting Help

- **Questions and ideas:** use [GitHub Discussions](https://github.com/Basit787/backend-file-based-routing/discussions).
- **Bugs:** open an [issue](https://github.com/Basit787/backend-file-based-routing/issues/new/choose)
  with a minimal route tree that reproduces it, the adapter you use, and the
  framework and Node.js versions.
- **Security problems:** follow [SECURITY.md](./SECURITY.md). Don't open a public issue.

Before asking, check the [README](./README.md) and [ARCHITECTURE.md](./ARCHITECTURE.md);
many "why does it work this way" questions are answered there.
